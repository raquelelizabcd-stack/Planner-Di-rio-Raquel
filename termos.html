1. Aceitação dos Termos

Ao acessar e utilizar o aplicativo Planner Diário Raquel, você concorda expressamente em cumprir e estar vinculado a estes Termos de Serviço. Este aplicativo é uma ferramenta de uso pessoal e de apoio analítico, com recursos avançados de inteligência artificial e controle de metas.

2. Uso de Serviços de Terceiros e APIs

O aplicativo se integra a provedores externos para funcionamento de determinadas abas, especificamente:

  • Google GenAI (Gemini API): Utilizado para geração de ideias e redação de conteúdos automatizados. O usuário é responsável por prover chaves de API válidas e pelo uso adequado dos tokens de IA.
  • Supabase Database: Usado para persistência segura de dados locais, histórico financeiro, tarefas e integrações.
  • APIs de Redes Sociais (Instagram Basic Display, Facebook Graph, LinkedIn Developer, TikTok Login): Conectadas de forma opcional para leitura de dados de engajamento e exibição de métricas unificadas.

3. Segurança de Dados e Credenciais

Todas as chaves de API e credenciais inseridas na seção de configurações são salvas de maneira restrita e utilizadas apenas para comunicação direta cliente-servidor com os respectivos provedores. Nós não vendemos nem compartilhamos chaves privadas ou dados gerados no diário pessoal.
